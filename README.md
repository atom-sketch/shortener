# Сервис сокращения URL

Сервис создаёт короткие ссылки, перенаправляет по ним и возвращает список ссылок текущего пользователя. Данные хранятся в памяти и исчезают при перезапуске. При каждом запуске сервер генерирует ключ HMAC-SHA256, поэтому ранее выданные cookie теряют силу.

## Запуск

Нужен Go 1.22 или новее. Выполните из корня проекта:

```sh
go run ./cmd/shortener
```

Сервис доступен по адресу `http://localhost:8080`.

## Проверка API

Команды ниже подходят для PowerShell. В Bash можно использовать `curl` вместо `curl.exe`.

Создайте короткую ссылку и сохраните cookie пользователя:

```powershell
'{"url":"https://example.com/some/long/path"}' | curl.exe -i -c cookies.txt -H "Content-Type: application/json" --data-binary "@-" http://localhost:8080/api/shorten
```

Сервер вернёт `201 Created` и JSON, например `{"result":"http://localhost:8080/1"}`. Принимаются абсолютные URL со схемой HTTP или HTTPS.

Проверьте редирект, подставив адрес из поля `result`:

```powershell
curl.exe -i http://localhost:8080/1
```

Сервер вернёт `307 Temporary Redirect` с исходным адресом в заголовке `Location`. Неизвестный идентификатор даст `404 Not Found`.

Получите ссылки пользователя с сохранённой cookie:

```powershell
curl.exe -i -b cookies.txt http://localhost:8080/api/user/urls
```

При наличии ссылок сервер вернёт `200 OK` и массив объектов с полями `short_url` и `original_url`. Если список пуст, ответ будет `204 No Content`. При отсутствии cookie или неверной подписи сервер выдаст новую cookie и вернёт `204`. Пустая cookie, отсутствие ID или некорректный формат дадут `401 Unauthorized`.

```sh
go test ./...
```

Тесты проверяют создание ссылок, редирект, подпись и замену cookie, изоляцию пользовательских списков и обработку некорректных запросов.
